欢迎阅读 OpenRLHF（人类反馈强化学习框架） 文档！

OpenRLHF 是首个高性能、可用于生产的开源 RLHF（人类反馈强化学习）框架，结合 Ray（分布式执行框架）+ vLLM（大模型推理引擎）分布式架构与统一的 agent（智能体）设计范式，实现可扩展且便于扩充的人类反馈强化学习。

主要特性

  • Ray + vLLM 分布式架构 —— 可扩展至 70B+ 模型。vLLM 加速生成，消除主要 RLHF 瓶颈；DeepSpeed（分布式深度学习优化库）ZeRO-3（零冗余优化器第 3 阶段）直接从 HuggingFace（模型生态平台）checkpoint（检查点）训练，无需模型转换。

  • 统一 agent 范式 —— token-in-token-out（词元输入输出）流水线将执行模式（单轮 / 多轮）与RL（强化学习）算法解耦。通过同一个共享损失层，任意算法可与任意模式搭配。

  • 最先进的 RL 算法 —— PPO（近端策略优化）、REINFORCE++（策略梯度算法）、REINFORCE++-baseline（带基线的 REINFORCE++）、GRPO（组相对策略优化）、Dr. GRPO（去除 GRPO 偏差的方法）、RLOO（留一法策略梯度），单一选项即可切换。

  • Hybrid Engine（混合引擎） —— 将 Actor（策略模型）/Critic（价值评估模型）/Reward（奖励模型）/Reference（参考模型）/vLLM 共置在同一组 GPU（图形处理器），通过休眠模式共享显存。小型集群利用率最高，部署最简单。

  • 异步训练与 Partial Rollout（部分采样） —— 重叠 rollout（采样生成）与训练，并通过 vLLM 暂停/恢复，将权重同步与生成重叠。已验证收敛性时吞吐量最高。

  • 单轮奖励与多轮 agent —— HTTP（网络协议）远程 RM（奖励模型）、自定义 Python 奖励函数（Reinforced Fine-Tuning（强化微调））、完整多轮环境，或将 vLLM 封装成 OpenAI 兼容聊天服务器。

  • Vision-Language Model（视觉语言模型）RLHF （0.10） —— 通过同一 agent 流水线，使用图像输入端到端训练 VLM（如 Qwen3.5）。

  • Muon（优化器） （0.10.2 新增） —— DeepSpeed 原生 MuonWithAuxAdam，用于 SFT（监督微调）/RM/DPO（直接偏好优化）/PPO。PPO 按实体选择（一行配置即可让 --actor.optim muon 配合 Adam（优化器）critic）。需要 DeepSpeed ≥ 0.18.2。

  • 分层 CLI（命令行接口） （0.10.2 新增） —— 每个选项属于具名分组（--ds.*、--vllm.*、--rollout.*、--data.*、--train.*、--eval.*、--ckpt.*、--logger.*、--algo.*、--actor.*、--critic.*、--ref.*、--reward.*）。层级体现所属组件，通过 --help 自带说明。

  • Off-policy（异策略）校正 —— TIS（截断重要性采样）/ICEPOP（重要性采样校正方法）/Seq-Mask-TIS（序列掩码截断重要性采样）处理 vLLM 与训练的对数概率不匹配。

  • 生产环境必备功能 —— 可恢复 checkpoint、最佳 checkpoint 跟踪、EMA（指数移动平均）、Wandb（实验跟踪平台）/TensorBoard（训练可视化工具）日志、SLURM（集群任务调度系统）多节点，以及用于 SFT/RM/DPO 的 LoRA（低秩适配）/QLoRA（量化低秩适配）。
