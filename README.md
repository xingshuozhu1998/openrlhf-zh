# OpenRLHF 中文文档

阅读地址：<https://xingshuozhu1998.github.io/openrlhf-zh/>。主页：<https://xingshuozhu1998.github.io/>。

这是官方文档 2026-10-06 的 latest 快照中文译本，并非实时更新或官方中文站。保留正文结构、代码、数学公式、外部链接、图片引用及原有版权信息。翻译和部署使用了 AI 辅助。

使用 GitHub Pages 从 main 分支根目录发布；`.nojekyll` 保留以下划线开头的资源目录。页面可直接作为静态文件托管，无需运行 Python 后端。资源解析服务仅作用于 /openrlhf-zh/，将已缓存的图片和公式资源映射到本站副本。

## 本地查看

在仓库的父目录运行 `python3 -m http.server 8000 --bind 127.0.0.1`，打开 `http://127.0.0.1:8000/openrlhf-zh/`。按 Ctrl+C 停止。

## 发布适配

调整站内根路径、Read the Docs 菜单数据和资源解析路径；将 0 处可定位到 HTML 的旧式 .rst/.md 链接改为静态 HTML 地址。原始译文快照保留在本地翻译目录。
