安装

推荐在 NVIDIA（英伟达） PyTorch（深度学习框架）容器内安装：

docker run --runtime=nvidia -it --rm --shm-size="10g" --cap-add=SYS_ADMIN \
    -v $PWD:/openrlhf nvcr.io/nvidia/pytorch:25.11-py3 bash

# remove packages that conflict with vLLM / flash-attn in the base image
pip uninstall xgboost transformer_engine flash_attn pynvml opencv-python-headless -y

# pip install (pick one)
pip install openrlhf                    # core only
pip install openrlhf[vllm]              # + vLLM 0.19.0 (recommended)
pip install openrlhf[vllm_latest]       # + vLLM > 0.19.0
pip install openrlhf[vllm,ring,liger]   # + ring-flash-attention + Liger

# or install from source
git clone https://github.com/OpenRLHF/OpenRLHF.git
cd OpenRLHF && pip install -e .

说明

建议 vLLM（推理引擎）0.19.0+ 获得最佳性能。Muon（矩阵参数优化器）还需要 DeepSpeed（分布式训练框架）≥ 0.18.2。参见 Dockerfiles 和 NVIDIA（英伟达） Docker（GPU（图形处理器） 容器支持，可选）。

A note on the CLI

OpenRLHF（人类反馈强化学习框架） 0.10.2 使用 hierarchical CLI（分层命令行接口），每个参数都位于点号分隔的配置部分前缀下。例如：

--actor.model_name_or_path Qwen/Qwen3-4B-Thinking-2507 \
--reward.remote_url examples/python/math_reward_func.py \
--data.prompt_dataset zhuzilin/dapo-math-17k \
--ds.zero_stage 3 \
--vllm.num_engines 2 \
--rollout.batch_size 128 \
--train.colocate_all \
--ckpt.output_dir ./exp/Qwen3-4B-Thinking

配置部分映射及完整旧参数 → 新参数迁移表见 常用 CLI（命令行接口）选项（参见 Flag migration (0.9.x / early 0.10 → 0.10.2)）。早期版本的平铺参数（--pretrain、--zero_stage、--vllm_num_engines 等）已无法解析。

First run (RLVR with Qwen3-4B)

这是文档贯穿使用的标准 RL（强化学习）示例：用 Python 奖励函数在数学推理中进行 REINFORCE++-baseline（带基线的策略梯度算法），无需训练奖励模型。需要 4 张 GPU（图形处理器）：

# 1) start ray on the head node
ray start --head --node-ip-address 0.0.0.0 --num-gpus 4

# 2) submit the training job
ray job submit --address="http://127.0.0.1:8265" \
   --runtime-env-json='{"working_dir": "/openrlhf"}' \
   -- python3 -m openrlhf.cli.train_ppo_ray \
   --actor.model_name_or_path Qwen/Qwen3-4B-Thinking-2507 \
   --reward.remote_url examples/python/math_reward_func.py \
   --data.prompt_dataset zhuzilin/dapo-math-17k \
   --data.input_key prompt \
   --data.label_key label \
   --data.apply_chat_template \
   --ds.packing_samples \
   --ref.num_nodes 1 --ref.num_gpus_per_node 4 \
   --actor.num_nodes 1 --actor.num_gpus_per_node 4 \
   --vllm.num_engines 2 --vllm.tensor_parallel_size 2 \
   --train.colocate_all \
   --vllm.gpu_memory_utilization 0.7 \
   --vllm.enable_sleep --ds.enable_sleep \
   --vllm.sync_backend nccl --vllm.enforce_eager \
   --algo.advantage.estimator reinforce_baseline \
   --algo.kl.use_loss --algo.kl.estimator k2 --algo.kl.init_coef 1e-5 \
   --rollout.batch_size 128 --rollout.n_samples_per_prompt 8 \
   --train.batch_size 1024 \
   --data.max_len 8192 --rollout.max_new_tokens 4096 \
   --ds.zero_stage 3 --ds.param_dtype bf16 \
   --actor.gradient_checkpointing_enable \
   --actor.adam.lr 5e-7 \
   --ckpt.output_dir ./exp/Qwen3-4B-Thinking

完整 recipe（训练方案，含 off-policy（异策略）校正、动态过滤、长度预算、ring attention（环形注意力）和检查点）见 Hybrid Engine（混合引擎）。替换为自己的数据集、RM（奖励模型）或多轮环境，参见 RL（强化学习）训练指南。

Prepare datasets

关键数据集参数（各 trainer（训练器）共用）：

  • --data.input_key：保存输入（文本或对话消息）的 JSON 键。

  • --data.apply_chat_template：使用 tokenizer（分词器）的 chat template。

  • --data.input_template：自定义模板字符串（对话模板的替代方案）。

  • --data.dataset_probs （SFT（监督微调）/RM/DPO（直接偏好优化）） / --data.prompt_probs （PPO（近端策略优化））：混合多个数据集（如 0.1,0.4,0.5）。

  • --eval.dataset：评估数据集路径。

对话模板示例：

dataset = [{"input_key": [
    {"role": "user", "content": "Hello, how are you?"},
    {"role": "assistant", "content": "I'm doing great. How can I help you today?"},
    {"role": "user", "content": "I'd like to show off how chat templating works!"},
]}]

tokenizer.apply_chat_template(dataset[0]["input_key"], tokenize=False)
# "<s>[INST] Hello, how are you? [/INST]I'm doing great. ...</s> [INST] ... [/INST]"

JSON 键约定因数据集类型而异，参见 Reward、SFT、Prompt 数据集模块。

Pretrained models

检查点兼容 HuggingFace（模型与工具平台）。通过以下参数让 trainer 使用它们：

  • --actor.model_name_or_path：actor（策略模型）/基座模型（PPO）。

  • --reward.model_name_or_path：奖励模型（PPO）。

  • --critic.model_name_or_path：critic（价值模型）（PPO，自动回退至 actor 或第一个奖励模型）。

  • --model.model_name_or_path：SFT / RM / DPO 训练的单个模型。

预训练示例位于 HuggingFace OpenRLHF。

Typical RLHF workflow

完整三阶段 RLHF（人类反馈强化学习）流水线：

  1. SFT（监督微调） → Supervised Fine-tuning (SFT)，位于 监督与偏好训练（SFT（监督微调）/RM（奖励模型）/DPO（直接偏好优化））。

  2. 奖励模型 → Reward Model (RM) Training，位于 监督与偏好训练（SFT（监督微调）/RM（奖励模型）/DPO（直接偏好优化））。

  3. RL 训练（Ray（分布式计算框架）+ vLLM）→ Quick Launch (Ray + vLLM)，位于 RL（强化学习）训练指南。

RLVR（可验证奖励强化学习）/推理工作负载可跳过步骤 1–2，使用自定义 Python 奖励函数直接进入步骤 3（见上文 首次运行 及 Single-Turn Mode (default)）。

自定义奖励、多轮环境、异步、VLM（视觉语言模型）等高级模式均见 RL（强化学习）训练指南。更多可运行脚本位于 examples/scripts 下。
