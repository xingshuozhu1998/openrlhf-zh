Checkpoint（检查点）保存与恢复

大模型训练成本高、耗时长，恢复能力至关重要。OpenRLHF（人类反馈强化学习框架） 在每个 checkpoint 保存四类状态：

  1. 模型权重 —— DeepSpeed（分布式深度学习优化库）格式（在 ZeRO（零冗余优化器）rank（进程编号）间分片）。

  2. 优化器与调度器状态 —— 用于精确恢复。

  3. 数据集进度 —— 通过重新实现的 resumable DistributedSampler 保存，避免重复训练已见数据。

  4. （可选）HuggingFace（模型生态平台）格式模型 —— 设置 --ckpt.save_hf 时，额外写入可部署的 HF checkpoint。

使用 --ckpt.load_enable 恢复时，若 checkpoint 目录存在但无有效 checkpoint，会平稳回退到从头训练，适用于首次运行或失败重启脚本。

Core flags

标志

含义

--ckpt.save_steps

两次 checkpoint 保存之间的全局训练步数（-1 = 从不保存）。对于 PPO（近端策略优化），步骤指模型更新步骤（非 mini-batch（小批次））。

--ckpt.path

Checkpoint 写入目录。

--ckpt.load_enable

从 --ckpt.path 恢复。目录无有效 checkpoint 时，回退到从头训练。

--ckpt.save_hf

每个 checkpoint 同时导出 HuggingFace 格式模型（便于不依赖 DeepSpeed 部署）。

--ckpt.disable_ds

跳过 DeepSpeed checkpoint 以节省磁盘——训练进度将无法恢复（仅保留 HF 格式模型）。

--ckpt.max_num

保留的 checkpoint 数量上限（删除最旧的）。

--ckpt.max_mem

Checkpoint 总大小上限，单位 GB。

--ds.use_universal_ckpt

使用 DeepSpeed Universal Checkpoint（通用检查点）格式（不依赖 ZeRO 阶段或 world size（进程总数））。

--ckpt.output_dir

最终 HuggingFace 格式模型保存路径（训练结束始终写入）。

PPO-only flags

标志

含义

--ckpt.best_metric_key

用于保存最佳 checkpoint的评估指标键（例如 eval_default_pass1）。空字符串自动检测评估集的第一个 pass1 指标；none 禁用最佳 checkpoint 保存。

--train.enable_ema

维护策略权重的 Exponential Moving Average（指数移动平均，EMA）副本，与普通模型一同保存。

--train.ema_beta

EMA 衰减率（默认 0.992）。越高，平均过程越慢。

--critic.save_value_network

同时保存 critic（价值评估模型）/价值网络 checkpoint。

跟踪最佳 checkpoint 需要评估：设置 --eval.dataset 与 --eval.steps，让 trainer（训练器）有可比较的指标。最佳 checkpoint 写入独立路径，避免最新与最佳 checkpoint 路径冲突。

DeepSpeed → Universal conversion

两次运行间更改 ZeRO 阶段或 world size 时，先将 DeepSpeed checkpoint 转为 Universal 格式：

bash examples/scripts/ckpt_ds_zero_to_universal.sh

然后使用 --ds.use_universal_ckpt 恢复。

Example: SFT

deepspeed --module openrlhf.cli.train_sft \
   --model.model_name_or_path meta-llama/Meta-Llama-3-8B \
   --data.dataset Open-Orca/OpenOrca \
   --data.input_key question \
   --data.output_key response \
   --data.input_template $'User: {}\nAssistant: ' \
   --data.max_samples 500000 \
   --data.max_len 2048 \
   --ds.packing_samples \
   --train.batch_size 256 \
   --train.micro_batch_size 2 \
   --train.max_epochs 1 \
   --adam.lr 5e-6 \
   --ds.zero_stage 2 \
   --ds.param_dtype bf16 \
   --ds.attn_implementation flash_attention_2 \
   --model.gradient_checkpointing_enable \
   --ckpt.output_dir ./checkpoint/llama3-8b-sft \
   --ckpt.path ./ckpt \
   --ckpt.save_steps 200 \
   --ckpt.save_hf \
   --ckpt.load_enable \
   --logger.logging_steps 1 \
   --eval.steps -1 \
   --logger.wandb.key {wandb_token}

Example: RL (Ray + vLLM)

要为 RL（强化学习）运行启用 checkpoint 保存，请在 Hybrid Engine（混合引擎） 的启动命令（或 多节点训练 的分布式版本）加入以下四个选项：

... \
--ckpt.save_steps 50 \
--ckpt.path /openrlhf/examples/checkpoint/ckpt/ \
--ckpt.save_hf \
--ckpt.load_enable
