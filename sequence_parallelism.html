Sequence Parallelism（序列并行，RingAttention）

OpenRLHF（人类反馈强化学习框架） 通过 RingAttention（环形注意力） 支持长上下文训练。这是一种序列并行注意力算法，将单个长序列分布到多张 GPU（图形处理器），同时重叠 KV-block（键值块）通信与分块注意力计算。参考：RingAttention paper 和 ring-flash-attention。

使用时机

以下情况启用 RingAttention：

  • 序列长度超过单张 GPU 容量（bf16（16 位脑浮点）+ flash-attn（高效注意力实现）时通常为 > 8K token（词元））。

  • 希望训练更长最大上下文，而不减小批次。

较短序列中，RingAttention 增加通信开销，应保持关闭（--ds.ring_attn_size 1）。

安装

pip install ring_flash_attn
# or install from source:
pip install git+https://github.com/zhuzilin/ring-flash-attention

或通过 ring extra（可选依赖组）安装 OpenRLHF：pip install openrlhf[vllm,ring,liger]。

参数

标志

含义

--ds.ring_attn_size

序列并行组大小。序列拆为相同数量的块，组内每 GPU 一块。

--ds.ring_attn_head_stride

每轮 RingAttention 处理的注意力头数（必须整除 num_attention_heads）。stride（步幅）越大，轮数越少、速度越快，但更耗显存；越小速度越慢，但峰值显存越低。

常见初始设置：--ds.ring_attn_size 2 --ds.ring_attn_head_stride 2。极长上下文可增大 ring_attn_size（如 4 或 8）；根据显存余量调节 ring_attn_head_stride。

说明

--ds.ring_attn_size > 1 要求 --ds.packing_samples（缺失时 trainer 会自动启用并警告）。

示例

SFT（监督微调）

deepspeed --module openrlhf.cli.train_sft \
   --model.model_name_or_path meta-llama/Meta-Llama-3-8B \
   --data.dataset Open-Orca/OpenOrca \
   --data.input_key question \
   --data.output_key response \
   --data.input_template $'User: {}\nAssistant: ' \
   --data.max_samples 500000 \
   --data.max_len 2048 \
   --ds.packing_samples \
   --train.batch_size 256 \
   --train.micro_batch_size 8 \
   --train.max_epochs 1 \
   --adam.lr 5e-6 \
   --ds.zero_stage 2 \
   --ds.param_dtype bf16 \
   --ds.attn_implementation flash_attention_2 \
   --model.gradient_checkpointing_enable \
   --ds.ring_attn_size 2 \
   --ds.ring_attn_head_stride 2 \
   --ckpt.output_dir ./checkpoint/llama3-8b-sft \
   --ckpt.save_steps -1 \
   --logger.logging_steps 1 \
   --eval.steps -1

DPO（直接偏好优化）

deepspeed --module openrlhf.cli.train_dpo \
   --model.model_name_or_path OpenRLHF/Llama-3-8b-sft-mixture \
   --data.dataset OpenRLHF/preference_dataset_mixture2_and_safe_pku \
   --data.apply_chat_template \
   --data.chosen_key chosen \
   --data.rejected_key rejected \
   --data.max_len 8192 \
   --ds.packing_samples \
   --train.batch_size 256 \
   --train.micro_batch_size 1 \
   --train.max_epochs 1 \
   --adam.lr 5e-7 \
   --model.beta 0.1 \
   --ds.zero_stage 3 \
   --ds.param_dtype bf16 \
   --ds.attn_implementation flash_attention_2 \
   --model.gradient_checkpointing_enable \
   --ds.ring_attn_size 2 \
   --ds.ring_attn_head_stride 2 \
   --ckpt.output_dir ./checkpoint/llama3-8b-ring-dpo \
   --ckpt.save_steps -1 \
   --logger.logging_steps 1 \
   --eval.steps -1 \
   --ckpt.load_enable

PPO（近端策略优化）/ GRPO（组相对策略优化）/ REINFORCE++

Ray（分布式计算框架）+ vLLM（推理引擎）的 RL（强化学习） trainer 支持相同参数。参见 train_ppo_ray_hybrid_engine.sh，取消底部 --ds.ring_attn_size 与 --ds.ring_attn_head_stride 行注释。

提示

RingAttention 配合 --ds.packing_samples 时，在序列分片 之前打包。因此 --train.micro_batch_size 控制每个 ring（环形并行组）看到多少个 打包后序列，而非原始样本数。
